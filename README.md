# Book Reading List Application

A responsive web application for managing a personal reading list.

## Live Demo

https://student-reading-list-ry4m.bolt.host

## Features

- Add books with a reading status
- Choose between Want to Read, Reading, and Finished
- Filter books by reading status
- Prevent duplicate book titles, ignoring capitalization and extra spaces
- Limit book titles to 60 characters
- Delete individual books
- View Total Books, Currently Reading, and Finished summary counts
- Responsive layout for desktop and mobile

## Technologies Used

- HTML
- CSS
- JavaScript
- Bolt
- GitHub
- Vercel

## Run Locally

1. Clone or download this repository.
2. Install dependencies if the project uses them.
3. Start the development server shown in the project files.
